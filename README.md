> **"Think Lethal Company with puzzles, without the capitalism!"**

**Laser Game** (Working Title) is a procedurally generating horror/puzzle game currently in development. Navigate dark, shifting mazes using only your wits and a laser pointer to uncover the path forward—or what's lurking in the dark.

## Features

* **Procedural Generation**: No two runs are the same. The maze shifts and changes every time you play.
* **Laser Pointer Mechanic**: Use your laser pointer to interact with puzzles, trigger sensors, and light up the terrifying unknown.
* **Atmospheric Horror**: A tense, immersive environment designed to keep you on edge.

## Getting Started

### Prerequisites

* **Unity Hub**
* **Unity Editor** (Check `ProjectSettings/ProjectVersion.txt` for the exact version, likely Unity 6 or newer)

### Installation

1.  Clone the repository:
    ```bash
    git clone [https://github.com/SamMcAulay/laserGame.git](https://github.com/SamMcAulay/laserGame.git)
    ```
2.  Open **Unity Hub**.
3.  Click **Add** and select the cloned `laserGame` folder.
4.  Open the project (Unity will import assets on the first launch).
5.  Navigate to `Assets/Scenes` and open the main scene to start playing.
